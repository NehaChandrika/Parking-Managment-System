🚗 Multi-Level Parking System Projects

This project implements the same parking system idea in three different versions, based on how parking spaces are arranged:

📌 Project Overview

🔹 Single-Line Parking System:
   Parking in a single row of slots
   Park, remove vehicles and check availability

🔹 Single-Floor Parking System:
   Parking in a grid layout (rows × columns)
   Park, remove and display the parking layout

🔹 Multi-Level Parking System:
   Parking across multiple floors
   Each floor has rows and columns

Full parking layout display for all floors

✨ Key Features:
Easy vehicle parking & removal
Prevents duplicate vehicle entries
Smart handling of full parking

Clear display using:
1D (Line)
2D (Floor)
3D (Multi-Level)

▶️ How to Run:
Make sure Python 3 is installed
Open Terminal / Command Prompt
Run the required version:
   python single_line_parking.py
   python single_floor_parking.py
   python multi_level_parking.py
Follow the on-screen instructions

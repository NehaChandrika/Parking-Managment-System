# Parking Management System 🚗

A simple command-line based Parking Management System built in Python.

## 🔧 Features
- Single-level, sequential parking simulation
- Slot allocation and deallocation
- Real-time tracking of free and occupied slots
- Command validation for `in`, `out`, and `exit`
- Graceful handling of full parking scenarios

## 🧠 Learning Outcome
- Strengthened understanding of arrays, loops, conditionals, and user input validation

## 🚀 How to Run
1. Make sure Python is installed
2. Run the script:
   ```bash
     python parking_system.py
   ```
